# Neon Harbor: Streets of Azul

A browser open-world driving game built for the make.fun "Make GTA 6" bounty (gta6-01), entered as @jemboods.

You arrive in the neon harbour city of Azul owing $100,000. Work 20 story jobs across 4 chapters to pay it off, and free-roam a stack of side systems: a 5-star police system with a searchlight helicopter, a weapon wheel, a camera drone, street races, buyable properties with garages, a bounty board, a mod shop, getaway contracts, rain weather, and a photo mode. Fully offline, no assets: the city, vehicles and all audio are generated in code (Three.js + WebAudio).

## Play

Open the GitHub Pages site for this repo, or serve this folder with any static file server and open index.html.

## Controls

- WASD / arrows: drive and walk
- E: enter or leave a car, interact
- Shift: handbrake and drift
- Space: jump while on foot
- Q (hold): weapon wheel, click to fire
- T: smartphone (Tab cycles pages)
- G: camera drone
- B: call your crew
- C: radio station
- Y: side gigs
- U: accept a getaway contract
- M: mod shop (at the garage)
- P: photo mode, F: take the shot
- H: horn
- N: new game (title screen), Continue resumes the save

Story payouts sum to exactly $100,000; everything else you earn is side money and never touches the debt ledger.
